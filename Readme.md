# Attend

**Attend** is an Android app built for students who are done doing attendance math in their head.

Track subject-wise attendance with live percentage calculation, know exactly how many classes you can safely miss before dropping below your required threshold, and keep marks, assignments, and holidays in one offline-first place — no more switching between five different apps and a notes file.

## Features
- 📊 **Attendance tracking** — mark present/absent/cancelled per subject, with a live "safe to bunk" calculator
- 🎯 **Mid-sem marks** — log scores across Mid Sem 1/2/3, with trend insights per subject
- 📝 **Assignment tracker** — due dates, reminders, pending/overdue/done states
- 📅 **Holiday calendar** — auto-excluded from attendance %, with reminders
- 🔁 **Missed-day catch-up** — flags days you forgot to mark and lets you backfill them
- 🎨 **Multi-color theming** — pick an accent color, toggle dark/light mode
- 📴 **Offline-first** — built on Room, no account or internet required

## Tech stack
- Java, MVVM, Room (local persistence)
- Android Jetpack components
